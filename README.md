# Portfolio
👨‍💻 Personal Portfolio — Tayyab Sajjad
A modern, fully responsive personal portfolio website built with vanilla HTML, CSS, and JavaScript. Designed to showcase my projects, skills, and experience as a FullStack Developer.

🚀 Live Demo
[View Portfolio
](https://tayyabsajjad76.github.io/Portfolio/)
✨ Features

Responsive design across all screen sizes (mobile, tablet, desktop)
Dark / Light mode toggle
Smooth scroll animations with reveal-on-scroll effects
Projects section with category filtering and paginated slider
Skills section with animated progress bars and arrow navigation
Contact form
Scroll-to-top button


🛠️ Tech Stack
Frontend: HTML5, CSS3, Vanilla JavaScript
Icons: Font Awesome
Fonts: Google Fonts
Deployment: GitHub Pages
