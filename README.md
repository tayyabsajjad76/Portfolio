## ✨ Features

- 📱 Fully responsive — mobile, tablet, and desktop layouts
- 🌙 Dark / Light mode toggle
- 🎞️ Smooth scroll animations with reveal-on-scroll effects
- 🗂️ Projects section with category filtering and paginated slider
- 📊 Skills section with animated progress bars and arrow navigation
- 📬 Contact form
- ⬆️ Scroll-to-top button
